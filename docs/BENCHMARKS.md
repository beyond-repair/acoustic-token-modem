# Benchmarks

Every experiment records:

Modulation · Bandwidth · Carrier count · Symbol rate · Raw bitrate · Payload bitrate · FEC overhead · PER · BER · SNR · Latency · Distance (or sim) · CPU · Memory

Store outputs under `benchmarks/results/` with a JSON sidecar of parameters.

**Token density** = successfully reconstructed token IDs / second under a specified channel condition.
